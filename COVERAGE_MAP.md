### Findings

**1. One region present, the other absent, in the same real month.**
- Del Monte Inventory Sign Off, 2023-02: Ilocos has 201 rows, Pangasinan has none.
- Del Monte Sell Out, 2023-11: Pangasinan file exists but is classified `?` (unknown), not merged with Ilocos — see Finding 4; if that reclassification is applied, this stops being a one-sided month.

**2. A month where every Del Monte family is simultaneously absent.**
- 2023-10: no staged file in any of Sell Out, Sales Register, Purchase Order, or Inventory Sign Off, for either region. Unilever (both `unilever_sku` and `ssis_summary`) has real data for 2023-10.

**3. A family-specific gap that doesn't affect its siblings in the same month.**
- 2023-12: Sell Out has zero rows for either region, but Sales Register, Purchase Order, and Inventory Sign Off all have real 2023-12 data. The Dec 2023 gap is Sell-Out-only, not a whole-month data-collection gap.

**4. Region classification breaks on old filenames, inconsistently.**
Files named with the `PANG_` abbreviation (not the full `PANGASINAN_`) land in `_region == "unknown"` instead of `pangasinan`, but only for a specific batch of 2023 files:
- `SEPTEMBER_2023_SELL_OUT__PANG_SELL_OUT.parquet`, `NOVEMBER_2023_SELL_OUT__PANG_SELL_OUT.parquet`, `2024_JANUARY_SELL_OUT__PANG_SELL_OUT.parquet`, `2024_FEBRUARY_SELL_OUT__PANG_SELL_OUT.parquet` (sell_out)
- `SEPTEMBER_2023_SALES_REGISTER__PANG_SALES_REG.parquet`, `NOVEMBER_2023_SALES_REGISTER__PANG_SALES_REG.parquet`, `DECEMBER_2023_SALES_REGISTER__PANG_SALES_REG.parquet` (sales_register)
- `SEPTEMBER_2023_PURCHASE_ORDER__PANG_PURCHASE.parquet`, `NOVEMBER_2023_PURCHASE_ORDER__PANG_PURCHASE.parquet`, `DECEMBER_2023_PURCHASE_ORDER__PANG_PURCHASE.parquet` (purchase_order)

This is not universal to every `PANG_`-prefixed file — the Oct/Nov 2025 `rmr_gs_bo` files (`PANG_BO`, `PANG_GS`) classify correctly as `pangasinan`. The break is specific to this older naming batch, not the abbreviation itself.

**5. `ssis_summary` carries no region split at all.**
Every real `ssis_summary` row has `_region == "unknown"` — this family has no per-region file structure the way the five Del Monte families do (it's a single consolidated SSIS export per month, split by sub-report — B.O Summary, Inventory, Invoice Reg, Raw Data, Sales Per Customer, SOH — not by region). This is the one file type whose region split is structurally different from every other file type in the corpus, not a gap.

**6. `inventory_sign_off` carries a third, uncategorized sheet alongside the two real regional sheets, in 6 real months.**
2025-03, 2025-04, 2025-06, 2025-08, 2025-09, 2025-12 each have three staged files: a correctly-classified Ilocos file, a correctly-classified Pangasinan file, and a third file from a generic `Sheet1`-named source (`_region == "unknown"`, 238 rows every single time — the row count does not vary month to month, unlike the two regional files). What this third sheet actually contains relative to the other two was not determined here — flagging its existence and its constant row count only.

**7. One `ssis_summary` source file's month could not be parsed at all.**
Seven sub-sheets sharing the filename stem `SSIS_DAILY_SALES_SUMMARY_REPORT_NOVEMBER_1_-_29_1` (B.O Summary, Inventory, Invoice Reg, Raw Data, Sales Per Customer ×2, SOH) all have `_period == "unknown"` — the day-range filename format (`NOVEMBER 1-29`) wasn't matched by whatever produced `_period` elsewhere. Internal content (`SOH_DEC_1_2021`) suggests November 2021, but that's not confirmed by the `_period` field itself.

**8. `ssis_summary` principal classification is not fully resolved either.**
144 of 805 real `ssis_summary` rows (~18%) have `_principal == "ambiguous"` rather than `unilever`; the remaining 661 are `unilever`. No row in this family is `delmonte`.
